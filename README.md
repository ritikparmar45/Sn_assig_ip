# SniperThink - Strategy Flow MVP

## How to run

1. **Start the backend:**
   ```bash
   cd backend
   node server.js
   ```

2. **Start the frontend:**
   ```bash
   cd frontend
   npm run dev
   ```

## Features Complete:
- Premium React Strategy Flow (Vite)
- Framer Motion scroll-based animations
- Progress Indicator scaling with scroll
- Axios integration with Node.js API
- Custom dark mode UI
